# 회고 산출물 포맷

회고를 **대화에 출력할 때**의 형태. 판정의 기록은 원장(`ledger.py` 가 쓰는 CSV)에, 분석과 결정은 세션 대화에 남고 세션을 봉인하면 스냅샷 본문에 보존된다.

출력은 둘로 나뉜다 — **작업 텍스트**(1~4단계, 사용자가 읽지 않아도 되는 재료)와 **최종 메시지**(사용자가 결정할 두 표).

## 작업 텍스트 (1~4단계)

항목당 한 줄, 축마다 2~4항목. 항목이 계속 늘면 세션을 더 잘게 나눴어야 한다는 신호다.

```md
**판정** — `{rule}` 부분작동: {사건 — 무엇을 했고 어디서 밟았나} · `{격리 rule}`(격리) 무관: {그 행동이 필요한 상황이 없었다}
**4축** — 실수(엔지니어링): … · 잘한 것(비즈니스): … · 어려웠던 것: … · 배운 것: X 일 때는 Y 한다
**🟢** — 1 {한 줄} b-insights → rule · 2 {한 줄} a-mistakes → 미분류(`{rule}` 가 커버)
**관련드묾 거름** — `{rule}`: 적용 범위가 거의 모든 구현 세션 → gate 관련드묾:reject
```

- 범주는 5범주 이름 — `a-mistakes` / `b-insights` / `c-improvements` / `d-deferred` / `e-recurring`. 정의는 SKILL.md 8단계.
- 미분류에는 사유를 적는다. 사유 없는 미분류는 매장이다.

## 최종 메시지

```md
## 회고 결정 — {날짜} · {프로젝트}

### 빼기
{ledger.py cards 출력 그대로 — 기준 줄 · 표 · 실패 사건 줄 · "격리 중" 줄 · "채점 기록 없는 rule" 줄. 거른 관련드묾 행만 빠진다}

### 더하기
{cards 출력 마지막의 정책 참고줄}

| # | 대상 | 제안 | 근거 | chars |
|---|---|---|---|---|
| 4 | `{rule}` | 보강 — 표 행 갱신 | {사건 한 줄} · 현재 판 작동 1/3 · 이전 판 15/28 | +180 |
| 5 | 신규 `{파일명}` | rule | {사건 한 줄} · 1회 관측 | 1,900 |

단서 — 5: {과거 반려 이력 / 인접 rule 과의 경계 / 발행 시 주의할 문구}

번호별로 답해 주세요 — 고치거나빼기는 고치기 / 격리 / 반려, 나머지 빼기는 accept / reject, 더하기는 accept / reject / edit. 반려와 문구 수정도 정당한 결과입니다.
```

## 규율

### 빼기

- `ledger.py cards` 출력을 **고치지 않고** 옮긴다. 숫자를 다시 쓰거나 반올림하지 않는다.
- 유일한 편집: `관련드묾` 행 중 `적용 범위` 가 넓은 rule 을 빼는 것 (사유는 작업 텍스트에, 기록은 gate).
- 빼기가 없으면 스크립트의 `없음 (원장 N행 · 회고 M회 읽음)` 줄을 그대로 — 빈 결과와 안 돈 결과를 구분하는 줄이다.
- P 를 해석할 때 창 길이를 같이 본다. 3세션짜리 창의 차이를 "보강이 효과 없었다" 같은 인과로 적지 않는다.

### 더하기

- 번호는 빼기 표에서 이어 매긴다.
- 보강 행은 `ledger.py stats` 의 `현재 판 · 이전 판` 을 근거 열에 — 이전 보강이 작동률을 올렸는지 보이는 숫자다.
- **chars 열**: 신규는 초안 길이, 보강은 증분. Python `len()` 으로 잰다 — bytes 가 아니라 chars 다 (한국어는 UTF-8 3 bytes/char 라 bytes 로 재면 3배로 보인다).
- 근거 열의 "k회 관측" 은 코퍼스 노드의 sources 수 (코퍼스가 없으면 이번 세션 1회) — 사실로만 적고 **정렬·등급에 쓰지 않는다**.
- 🟢 가 없으면 `없음 — {이유 한 줄}`.

## 안티패턴

- ❌ 최종 메시지에 분석 전문을 다시 붙이기 — 두 표 말고는 작업 텍스트에 있다
- ❌ "승격 확률 0.7" 처럼 스크립트가 내지 않은 확률
- ❌ 빼기 표를 더하기 표 뒤에 배치 (줄일 것을 먼저 본다)
- ❌ 실수 축에 "특별히 없음"
- ❌ "테스트 통과함, 잘 진행됨" 류의 검증 불가능한 근거
- ❌ 🟢 후보를 선택지 버튼으로 제시 (읽기가 강제되지 않아 거수기가 된다)
- ❌ 코드 diff 나열 — 회고는 무엇을 했는지가 아니라 **무엇을 알게 됐는지**다
